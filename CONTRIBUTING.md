# Contributing

This is a working document, not a finished product. PRs and issues welcome.

Most useful contributions, in order:

1. You tried this and something broke. Say what.
2. You have a way to capture decisions made on calls or in Slack, where no agent is present.
3. You've kept a decision log going past week three. What made it stick.
4. You made this work for non-engineering decisions.
5. A cleaner hook for Codex, Cursor or another agent.

Keep the README short. If your change makes it longer, it probably belongs in a separate file.

No em-dashes, no bullet-point essays. Write like you're explaining it to a colleague.
