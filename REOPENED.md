# Re-opened

Every time a decision already in DECISIONS.md gets argued again because someone didn't know it was settled, add one line here. Append only, newest at the bottom. This is the one number we track: if it doesn't drop, the repo isn't working.

Re-opening a decision on purpose because its "Revisit if" condition came true doesn't count. That's the system working.

Format: `YYYY-MM-DD  D-00N  who, and one line on what happened`
